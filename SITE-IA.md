# Cochranweb.com — Site Information Architecture

**Positioning:** Scale Readiness Validator for Series A SaaS  
**Primary CTA:** Take the Scale Readiness Snapshot  
**Secondary CTA (gated):** Book a 15-minute fit call (shown only after Snapshot qualification)

---

## Pages & Navigation

| Page | Path | Purpose |
|------|------|---------|
| **Home** | `/` (index.html) | Single outcome + ICP + recognition + offer summary + proof snippets + process + CTA to Snapshot. No open booking link. |
| **Scale Readiness** | `/scale-readiness.html` | Deeper detail on the offer: diagnostic scope, deliverables, boundaries, who it’s for. No deep jargon. CTA: Snapshot. |
| **Snapshot** | `/snapshot.html` | Explains the questionnaire, what happens next (qualified → fit call; unqualified → polite decline), privacy. Hosts or links to the 3-min Snapshot form. |
| **About** | `/about.html` | Resume-like content: bio, experience timeline, advisory roles. For credibility; not the main conversion path. |

---

## Navigation (global)

- Home  
- Scale Readiness  
- Snapshot *(or "Take the Snapshot" as CTA-style link)*  
- About  

Footer: Contact (email, LinkedIn), optional location. No phone prominence on homepage.

---

## Funnel Flow

1. **Landing** → Home or Scale Readiness  
2. **Qualification** → Snapshot (3-min questionnaire)  
3. **Qualified** → 15-min fit call (link/booking revealed only after Snapshot)  
4. **Engagement** → Scale Readiness Diagnostic (4–6 weeks)

---

## Content Boundaries

- **Homepage:** No DDD/SOLID/CQRS/volatility decomposition. Executive, calm, direct.  
- **Scale Readiness:** Same tone; more detail on deliverables and boundaries.  
- **Snapshot:** Practical (what we ask, what happens, privacy).  
- **About:** Full resume/career content; technical terms acceptable here if needed.  
- **Deep technical:** Optional future page (e.g. `/technical` or `/approach`) for methodology details — not linked from main nav.
